{ Study Tips }

General Study Tips:

  • Set one clear goal per session (ex: “finish 20 flashcards” or “do 5 problems”), not “study I2201.”
  • Use active recall: test yourself without notes before checking answers.
  • Do spaced repetition: review the same study material over multiple days instead of cramming.
  • Study in focused sprints: 25–45 minutes work, 5–10 minutes break.
  • Make a mistake log: write what you got wrong + why + the correct method.
  • Teach it out loud: explain the concept simply to prove you actually understand it.
  • Protect focus: phone away, notifications off, one-tab rule.

Web Development Study Tips:

  • Build tiny UI components weekly: navbar, cards, modal, login form—small + finished.
  • Practice CSS layout on purpose: flexbox + grid + spacing; recreate a section from a screenshot.
  • Use DevTools constantly: inspect elements, check computed styles, hover/focus states, and console errors.
  • Learn DOM + events deeply: query selectors, event listeners, event bubbling, classList, and form handling.
  • Debug systematically: change one thing at a time, console.log, isolate the bug, then fix.
  • Write clean structure first: semantic HTML (header/nav/main/section), then style, then JS behavior.
  • Create a personal snippet library: common patterns (center layouts, responsive cards, fetch + render list, form validation).
